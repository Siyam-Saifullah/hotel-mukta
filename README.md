- **Direct WhatsApp Booking Engine:** Direct, frictionless reservations via WhatsApp (`+880 1711-302322`) and front desk hotlines with pre-formatted inquiry messages.
- **Dual Language Support:** Seamless instant toggle between **English** and **বাংলা** (Bengali) across all sections, rooms, and forms.
- **Midnight Gold & Deep Slate Aesthetic:** Dark luxury theme with champagne gold gradients, glassmorphism, glowing micro-interactions, and custom typography (`Cinzel`, `Plus Jakarta Sans`, `Hind Siliguri`).
- **Real Verified Photography:** Extracted high-resolution photography for Exterior, Reception, Lobby, Deluxe Twin, Premium Twin, and Triple Family Suite.
- **Interactive Features:**
  - Fast Availability & WhatsApp Inquiry Bar
  - Filterable Photo Gallery with Fullscreen Lightbox
  - Interactive Room Quick Specs Modal
  - Rajshahi City Distance Guide & Embedded Google Maps

## 🚀 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Siyam-Saifullah/hotel-mukta.git
   cd hotel-mukta
   ```

2. Open `index.html` in your web browser or serve with any static HTTP server:
   ```bash
   python -m http.server 8080
   ```
   Open `http://localhost:8080` in your browser.
